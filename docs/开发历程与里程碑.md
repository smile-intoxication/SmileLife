# 开发历程与里程碑

> 本文件是从工作区根目录的 `AGENTS.md` **移出来**的。
> 原因：`AGENTS.md` 是每轮都要读进上下文的工作区指令文件，它撞到了
> **64 KB 的指令预算上限** —— 超出的部分会被**从文件末尾静默截断**（实测发生过两次）。
> 那比文件短一点但完整要糟得多，所以做了这个拆分。
>
> 分工：
> - **`AGENTS.md`** 放"当前状态 + 版本表 + 环境事实 + 踩过的坑"（每轮都要用到的）
> - **本文件**放按时间顺序的编年史（每一版为什么这么做、当时的取舍）—— 需要时才读
